Where texts come from

Degrau does not rewrite anything on its own. Claude Code does the adapting, in this repository, and leaves the result in inbox/ for the app to check and store.

  1. Run the command in Claude Code, pointing it at a file or a URL: 
    /adapt {{ level }} caminho/para/materia.txt
    It reads your profile, adapts the text to that level, writes the JSON and imports it. Usually nothing else is needed — the text is already here when it finishes.
  2. Or press Import waiting texts if a document is sitting in inbox/ and was not imported yet.
  3. Or paste the document, when the JSON came from somewhere else — another conversation, another machine.
